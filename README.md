Matchmaker 2.0 serves to to replace the legacy Matchmaker spreadsheet used by Quality Techs to populate FAIR templates submitted to Net Inspect. This version removes the need to reformat, copy, and paste spreadsheets, while maintaining and expanding upon the original functionality of the Matchmaker.

PREREQUISITES:
Prior to running, the user should ensure the following documents are available:
* BOM (.xls or .xlsx)
* CBOM (.xls or .xlsx)
* As Built (.xls or .xlsx)
* FA Report (.pdf)

This application is currently only compatible with Windows. Expansion to other OS is unlikely.

INSTRUCTIONS:
* User opens application
* User attaches appropriate files (via File Explorer navigation or drag-and-drop)
* User can hit "x" to remove individual files or "Reset" to clear all uploads
* User clicks "Go" to generate report
* User will be prompted to save auto-populated template for Net Inspect submission

KNOWN ISSUES:
* This application is designed to be compatible with documents used by Spartronics Logan. Use for other sites or companies will likely require modification to process files as formatted
* Form 2 features are currently only partially automated; Form 3 is not yet automated
* PDF processing only works for "readable" PDFs, not yet for image-only or scanned
Contact kira.carr@spartronics.com to report bugs and issues.
